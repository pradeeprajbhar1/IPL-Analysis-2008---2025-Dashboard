# 🏏 IPL Analysis Dashboard (2008–2025) | Power BI

## 📌 Project Overview
This project is an interactive Power BI dashboard that provides comprehensive insights into the Indian Premier League (IPL) from 2008 to 2025. It helps analyze team performance, player statistics, tournament results, and season-wise trends through interactive visualizations.

---

## 🚀 Features
- Season-wise IPL Analysis (2008–2025)
- Champions & Runner-up
- Orange Cap & Purple Cap Statistics
- Total Matches, Teams, Venues
- Total Fours & Sixes
- Points Table
- Interactive Season Slicer
- Clean and User-Friendly Dashboard

---

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

---

## 📊 Dashboard Insights
- IPL Champions by Season
- Runner-up Team
- Orange Cap Winner
- Purple Cap Winner
- Total 4's & 6's
- Team Performance Analysis
- Season-wise Statistics
- Points Table Analysis
